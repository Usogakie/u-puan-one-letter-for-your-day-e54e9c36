One letter for my day: **Z** — zombie. A day spent shuffling through
everything on autopilot, half asleep, running on nothing. Zero sleep,
zombie mode: the most vivid, funny, and honest single letter for it.

## Run it

```sh
python3 main.py
```

The program writes exactly one character, `Z`, to
`${MAKEFUN_OUTPUT_DIR:-/output}/entry.txt` and nothing else.
